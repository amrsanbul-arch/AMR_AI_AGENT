# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. تتضمن لوحة عربية/إنجليزية متجاوبة، ومساعد محتوى محليًا، وهيكلًا لتكامل Instagram Login الرسمي. لا يوجد حساب Instagram حي متصل في هذه النسخة.

## تشغيل لوحة التحكم

يتطلب Node.js 20+ وpnpm:

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Next.js. الواجهة متجاوبة وتدعم العربية RTL والإنجليزية. مساعد المحتوى يجهز مسودات أفكار وكابشنات وسيناريوهات محلية قابلة للتحرير؛ لا يستخدم نموذجًا خارجيًا ولا ينشر تلقائيًا. التقويم والتحليلات ما زالت هياكل أولية.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload --no-access-log
```

`--no-access-log` يمنع سجل Uvicorn من تسجيل عنوان callback الذي قد يحتوي على رمز تفويض مؤقت. افتح `/healthz` أو `/docs`. مسارات الحساب وInstagram تتطلب جلسة مالك؛ حالة جلسة تسجيل الدخول متاحة من `/api/auth/session`. عند استخدام reverse proxy، اضبط سجلاته كي لا تحفظ query string لمسار `/api/instagram/callback`.

## Instagram Login الرسمي (مرحلة تمهيدية، غير موصلة)

تمت إضافة مسارات OAuth الرسمية مع أقل صلاحية للقراءة الأساسية (`instagram_business_basic`)، والتحقق من `state` بملف تعريف ارتباط HttpOnly قصير العمر، وتبادل authorization code على الخادم، وتشفير رمز الوصول طويل العمر في SQLite باستخدام Fernet. لا تُعاد الرموز السرية في الاستجابات، ولا توجد بيانات حساب مضمّنة. تُستخدم فقط نطاقات Instagram الرسمية (`instagram.com`, `api.instagram.com`, `graph.instagram.com`). نقاط القراءة تعيد بيانات الحساب الأساسية والمنشورات، ولا تعرض رمز الوصول أو رسائل Meta الخام.

قبل الاختبار يدويًا، يلزم إعداد تطبيق Meta للمطور وتحديد Instagram Login وإضافة Redirect URI المطابق تمامًا. شغّل API محليًا بخدمة مالك محمية: أنشئ كلمة مرور قوية من 14 حرفًا على الأقل، خزّن hash فقط، وأنشئ سر جلسة عشوائي. لا تُرسل كلمة المرور إلى المحادثة ولا تضعها في Git. ضع القيم محليًا في `.env` (لا ترفع الملف إلى Git):

```sh
cp .env.example .env
# أنشئ AMR_OWNER_PASSWORD_HASH وAMR_SESSION_SECRET بالأوامر المعلّقة في .env.example
```

املأ `AMR_OWNER_PASSWORD_HASH`, `AMR_SESSION_SECRET`, `META_APP_ID`, `META_APP_SECRET`, `META_REDIRECT_URI=http://localhost:8000/api/instagram/callback`. أنشئ `INSTAGRAM_TOKEN_ENCRYPTION_KEY` محليًا بالأمر الموجود في `.env.example`. حمّل متغيرات `.env` في جلسة الطرفية قبل تشغيل الخادم (الملف لا يُحمّل تلقائيًا):

```sh
set -a
. ./.env
set +a
uv run uvicorn app.main:app --app-dir api --reload --no-access-log
```

لا ترسل أسرار Meta أو مفتاح التشفير إلى Wabi أو GitHub. بعد تسجيل دخول المالك عبر `POST /api/auth/login` (JSON `{ "password": "…" }`)، يمكن بدء التدفق من `/api/instagram/connect`. نقاط القراءة `/api/instagram/account` و`/api/instagram/media?limit=25` تستعلم من Graph API الرسمي فقط بعد الاتصال؛ الثانية تدعم `after` كمؤشر pagination وتعيد cursor فقط، لا رابط pagination خارجي. الحالة من `/api/instagram/status`; حذف الرمز المحفوظ محليًا عبر `POST /api/instagram/disconnect`. سجّل الخروج عبر `POST /api/auth/logout`. لا توجد واجهة تسجيل دخول في الويب حتى الآن؛ هذه المرحلة تضيف API المصادقة وقراءة الحساب فقط.

مصادقة المالك تستخدم كلمة مرور مخزنة كـ PBKDF2-SHA256 hash، جلسة موقعة قصيرة (12 ساعة) في cookie HttpOnly/SameSite=Lax، وفحص Origin للطلبات المعدّلة مع حد محاولات دخول محلي. في الإنتاج تكون cookie Secure ويلزم HTTPS وتهيئة مصادقة المالك؛ لا يُفعّل OAuth إذا غابت. حد المحاولات داخل الذاكرة لكل عملية تشغيل، لذا أضف rate limiting في reverse proxy عند تعدد العمال أو التعرض العام. إعدادات التطوير تسمح فقط بعنوان callback محلي أو HTTPS ثابت على مسار callback المحدد. رموز OAuth تمر في طلبات الخادم المطلوبة من Meta؛ لا تفعّل سجلات HTTP أو proxy التي تحفظ query string لهذه الطلبات/المسارات.

التدفق لا يمنح إلا صلاحية الملف الأساسي؛ لا يوجد نشر أو قراءة Insights أو التعليقات أو الرسائل بعد. إضافة كل صلاحية أخرى تتطلب مطابقة وثائق Meta الحالية ومراجعتها واختبارها منفصلًا. لا يغيّر disconnect الصلاحيات لدى Meta؛ يلزم إلغاء التطبيق من إعدادات Instagram عند الحاجة. إدارة صلاحية الرمز وتجديده ستضاف عند تنفيذ استخدام API الفعلي.

## مساعد المحتوى

المولّد الحالي محلي مجاني وحتمي، وليس نموذج AI/LLM. يجهز أفكارًا وكابشنات وسيناريوهات Reel قابلة للتعديل ولا يستخدم بيانات الحساب أو الإنترنت. النتائج مسودات وليست توصيات مبنية على أداء منشورات حقيقية.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

اختبارات Instagram تستبدل طلبات Meta بمحاكاة محلية؛ لا تتصل بالإنترنت ولا تنشئ اتصالًا حيًا أو بيانات مستخدم. تشمل مصادقة المالك والجلسات وقيود Origin، تدفق OAuth/CSRF والتشفير، وقراءة الحساب والمنشورات من Graph عبر mocks، إضافة إلى الفصل المحلي.

## التكلفة والحدود الحالية

لا توجد رسوم متعمدة أو خدمات مدفوعة في مرحلة OAuth هذه؛ تشغيل الاختبارات محلي ومجاني. لا نضمن استمرار الخطط المجانية للاستضافة، ولا تشمل التكاليف استضافة فعلية أو نطاقًا أو ميزات نماذج ذكاء اصطناعي مستقبلية. لا توجد رسوم API معلومة لنا هنا، لكن الوصول يتطلب تطبيق Meta وموافقاتها وقد تتغير الصلاحيات والحدود.

## المراحل

1. هيكل FastAPI/Next.js واختباره (منجز).
2. لوحة عربية/إنجليزية متجاوبة بحالات فارغة صريحة (منجز).
3. مساعد محلي للأفكار والكابشنات وسيناريوهات Reels (منجز؛ لا يستخدم LLM).
4. هيكل OAuth رسمي آمن وتجارب mock فقط (تمت إضافة جلسة مالك ونقاط قراءة API؛ لم يختبر حسابًا حيًا).
5. إعداد تطبيق Meta ومصادقته ثم اختبار ربط حي بموافقة المالك؛ التحليلات المتقدمة والنشر والجدولة ما زالت مراحل لاحقة.

## الإعدادات

لا توجد مفاتيح خارجية مطلوبة لتجربة لوحة التحكم ومساعد المحتوى محليًا. الواجهة تستخدم `http://localhost:8000` كعنوان API افتراضي؛ اضبط `NEXT_PUBLIC_API_BASE_URL` عند نشر واجهة وخادم على نطاقات معلومة، و`WEB_ORIGIN` للسماح بأصل الواجهة فقط. للاستخدام من الهاتف، افتح نشرًا خاصًا محميًا أو شبكة محلية مضبوطة؛ لا تستخدم `localhost` على الهاتف للإشارة إلى جهاز التطوير. لا تفتح OAuth على الإنترنت قبل وجود مصادقة للمالك.

انسخ `.env.example` إلى `.env` عند الحاجة. لا ترفع ملفات `.env` أو قاعدة بيانات الرموز إلى GitHub.

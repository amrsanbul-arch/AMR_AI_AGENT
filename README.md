# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. تتضمن لوحة عربية/إنجليزية متجاوبة، ومساعد محتوى محليًا، وهيكلًا لتكامل Instagram Login الرسمي. لا يوجد حساب Instagram حي متصل في هذه النسخة.

## تشغيل لوحة التحكم

يتطلب Node.js 20+ وpnpm:

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Next.js. الواجهة متجاوبة وتدعم العربية RTL والإنجليزية. مساعد المحتوى يجهز مسودات أفكار وكابشنات وسيناريوهات محلية قابلة للتحرير؛ لا يستخدم نموذجًا خارجيًا ولا ينشر تلقائيًا. يتضمن الاستوديو بحثًا عند الطلب في مؤشرات Google Trends العامة (ليس بيانات Instagram)، وتبويب النشر مسودات وقرار نشر فوري أو جدولة بموافقتك الصريحة.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload --no-access-log
```

`--no-access-log` يمنع سجل Uvicorn من تسجيل عنوان callback الذي قد يحتوي على رمز تفويض مؤقت. افتح `/healthz` أو `/docs`. مسارات الحساب وInstagram تتطلب جلسة مالك؛ حالة جلسة تسجيل الدخول متاحة من `/api/auth/session`. عند استخدام reverse proxy، اضبط سجلاته كي لا تحفظ query string لمسارات callback أو Graph API.

## المساعد المحادثي (أوامر محدودة)

افتح `/assistant` من رابط «المساعد المحادثي» في لوحة التحكم. يقبل أوامر قصيرة بالعربية المصرية/العربية أو الإنجليزية ضمن نطاق واضح: أفكار وكابشنات وReels، بحث مؤشرات Google Trends، قراءة تحليلات Instagram الرسمية، مراجعة حقول الملف المتاحة، تقرير استراتيجية، أو فتح تقويم النشر. إذا احتاج الأمر موضوعًا ولم يذكره، يسأل المساعد عن الموضوع قبل تشغيل الأداة. الطلبات غير المدعومة، ومنها النشر أو تعديل الملف، لا تُنفذ من المحادثة؛ تظل الموافقة الموجودة في شاشة النشر مطلوبة.

توجيه الطلبات حتمي ومحدود، وليس وكيلًا عامًا ولا محادثة حرة مع نموذج. المحتوى النصي يستخدم `/api/content/generate` و`/api/content/reel-studio`؛ قوالب مجانية تعمل افتراضيًا، ويمكن استخدام Ollama المحلي الاختياري وفق إعدادات المصادقة السابقة. التحليلات ومراجعة الملف وتقرير الاستراتيجية والبحث المحمي تستخدم نقاط النهاية الحالية وتتطلب جلسة المالك. لا تخزّن الواجهة نص المحادثة أو أسرارًا، ولا تعرض HTML من الاستجابة. التحليلات لا تعمل قبل ربط Instagram الرسمي، والبيانات الناقصة تظل غير متاحة بدل تخمينها. Google Trends يعطي إشارات بحث عامة فقط، وليس اتجاهات Instagram أو بيانات جمهور الحساب.

اختبار موجّه الأوامر من مجلد `web`: `pnpm test:intents`.

## Instagram Login الرسمي (مرحلة تمهيدية، غير موصلة)

تمت إضافة مسارات OAuth الرسمية بصلاحيات القراءة الأساسية (`instagram_business_basic`) وInsights (`instagram_business_manage_insights`) والنشر (`instagram_business_content_publish`)، والتحقق من `state` بملف تعريف ارتباط HttpOnly قصير العمر، وتبادل authorization code على الخادم، وتشفير رمز الوصول طويل العمر في SQLite باستخدام Fernet. لا تُعاد الرموز السرية في الاستجابات، ولا توجد بيانات حساب مضمّنة. تُستخدم فقط نطاقات Instagram الرسمية (`instagram.com`, `api.instagram.com`, `graph.instagram.com`). نقاط القراءة تعيد بيانات الحساب الأساسية والمنشورات وInsights، ولا تعرض رمز الوصول أو رسائل Meta الخام.

قبل الاختبار يدويًا، يلزم إعداد تطبيق Meta للمطور وتحديد Instagram Login وإضافة Redirect URI المطابق تمامًا. شغّل API محليًا بخدمة مالك محمية: أنشئ كلمة مرور قوية من 14 حرفًا على الأقل، خزّن hash فقط، وأنشئ سر جلسة عشوائي. لا تُرسل كلمة المرور إلى المحادثة ولا تضعها في Git. ضع القيم محليًا في `.env` (لا ترفع الملف إلى Git):

```sh
cp .env.example .env
# أنشئ AMR_OWNER_PASSWORD_HASH وAMR_SESSION_SECRET بالأوامر المعلّقة في .env.example
```

املأ `AMR_OWNER_PASSWORD_HASH`, `AMR_SESSION_SECRET`, `META_APP_ID`, `META_APP_SECRET`, `META_REDIRECT_URI=http://localhost:8000/api/instagram/callback`. أنشئ `INSTAGRAM_TOKEN_ENCRYPTION_KEY` محليًا بالأمر الموجود في `.env.example`. حمّل متغيرات `.env` في جلسة الطرفية قبل تشغيل الخادم (الملف لا يُحمّل تلقائيًا):

```sh
set -a
. ./.env
set +a
uv run uvicorn app.main:app --app-dir api --reload --no-access-log
```

لا ترسل أسرار Meta أو مفتاح التشفير إلى Wabi أو GitHub. بعد تسجيل دخول المالك عبر `POST /api/auth/login` (JSON `{ "password": "…" }`)، يمكن بدء التدفق من `/api/instagram/connect`. نقاط القراءة `/api/instagram/account` و`/api/instagram/media?limit=25` تستعلم من Graph API الرسمي فقط بعد الاتصال؛ الثانية تدعم `after` كمؤشر pagination وتعيد cursor فقط، لا رابط pagination خارجي. التحليلات على `/api/instagram/insights?days=7` (المدى 1–90 يومًا) و`/api/instagram/media/{media_id}/insights`؛ مصدر القيم Instagram Insights الرسمي، ولا تتحول القيم غير المتاحة إلى أصفار. أضيف `/api/instagram/performance/content?limit=12` لترتيب آخر عينة معادة من الوسائط التي توفر Meta لها كلاً من `like_count` و`comments_count`؛ يعرض الأعلى في المنشورات وReels، ويُظهر العناصر ذات المقاييس الناقصة خارج الترتيب بدل اعتبارها أصفارًا. إصدار Graph مضبوط عبر `META_GRAPH_API_VERSION` (الافتراضي الحالي `v27.0`) ليظل قابلًا للتحديث. الحالة من `/api/instagram/status`; حذف الرمز المحفوظ محليًا عبر `POST /api/instagram/disconnect`. سجّل الخروج عبر `POST /api/auth/logout`. واجهة الويب تتضمن تسجيل دخول مالك محميًا (لا تحفظ كلمة المرور)، وتعرض حالة الربط وبيانات الحساب والمنشورات التي يعيدها API. عند نجاح OAuth يعود المتصفح إلى الواجهة ثم تتحقق الواجهة من حالة الاتصال. لا توجد بيانات Instagram معروضة قبل نجاح الربط.

مصادقة المالك تستخدم كلمة مرور مخزنة كـ PBKDF2-SHA256 hash، جلسة موقعة قصيرة (12 ساعة) في cookie HttpOnly/SameSite=Lax، وفحص Origin للطلبات المعدّلة مع حد محاولات دخول محلي. في الإنتاج تكون cookie Secure ويلزم HTTPS وتهيئة مصادقة المالك؛ لا يُفعّل OAuth إذا غابت. حد المحاولات داخل الذاكرة لكل عملية تشغيل، لذا أضف rate limiting في reverse proxy عند تعدد العمال أو التعرض العام. إعدادات التطوير تسمح فقط بعنوان callback محلي أو HTTPS ثابت على مسار callback المحدد. رموز OAuth تمر في طلبات الخادم المطلوبة من Meta؛ لا تفعّل سجلات HTTP أو proxy التي تحفظ query string لهذه الطلبات/المسارات.

النشر يدعم صورة أو فيديو أو Reel عبر نقاط Meta الرسمية `/{ig-user-id}/media` ثم `/{container-id}` لفحص المعالجة ثم `/{ig-user-id}/media_publish`. لا توجد جدولة أصلية من Meta هنا؛ التطبيق يحفظ موافقة منفصلة لمحتوى محدد ويشغّل جدولة محلية عند `INSTAGRAM_SCHEDULER_ENABLED=true`. يحتاج الخادم إلى البقاء عاملًا في الموعد؛ الاستضافة المجانية التي تتوقف أو تنام قد تؤخر المنشور. لا يوجد نشر تلقائي قبل موافقة صريحة لكل منشور مجدول. إذا لم يصل رد نهائي من Meta بعد محاولة النشر، تُحفظ الحالة `unknown` ولا تحدث إعادة محاولة آلية منعًا للتكرار. الإلغاء متاح قبل النشر فقط. لا يدعم هذا الإصدار المنشورات الدوّارة (carousel) أو التحليلات المتقدمة. صلاحيات وMetrics Insights التي تعيدها Meta قد تختلف حسب نوع الوسيط، حجم الحساب، إصدار API والمراجعة، وقد تتأخر أو لا تتوفر؛ التطبيق يعرض غياب القيمة بدل اختلاقها. لم يُختبر اتصال حي. إضافة كل صلاحية أخرى تتطلب مطابقة وثائق Meta الحالية ومراجعتها واختبارها منفصلًا. لا يغيّر disconnect الصلاحيات لدى Meta؛ يلزم إلغاء التطبيق من إعدادات Instagram عند الحاجة. إدارة صلاحية الرمز وتجديده ستضاف عند تنفيذ استخدام API الفعلي.

### النشر والجدولة

بعد إعداد نطاق `instagram_business_content_publish` في تطبيق Meta وربط حساب Creator/Business، احفظ مسودة من تبويب «تقويم النشر» برابط وسائط HTTPS عام يمكن لـ Meta الوصول إليه. راجع نص الكابشن والرابط والنوع الظاهرين ثم اضغط «أوافق وانشر الآن» أو اختر وقتًا محليًا واضغط «أوافق وجدول النشر». كل موافقة تُربط ببصمة المحتوى المعروض؛ لا يمكن تعديل مسودة بعد اعتمادها. المسارات: `POST /api/instagram/posts`, `GET /api/instagram/posts`, `POST /api/instagram/posts/{id}/approve`, `POST /api/instagram/posts/{id}/cancel`. شغّل `INSTAGRAM_SCHEDULER_ENABLED=true` فقط في عملية API مستقرة بقرص SQLite دائم؛ المعالجة كل 20 ثانية. تشغيل أكثر من عملية آمن من ناحية الحجز المحلي، لكن لا تنشر من عدة نسخ منفصلة بقاعدة بيانات غير مشتركة. لا تخزن رموز Instagram في الواجهة. اختبارات النشر محاكاة محلية؛ لم تُنشر أي مادة فعلية ولم يُختبر حساب حي.

## مساعد المحتوى واستوديو Reels

المولّد الحالي محلي مجاني وحتمي، وليس نموذج AI/LLM. يجهز أفكارًا وكابشنات، واستوديو Reels يخرج لوحة من أربعة مشاهد بتوقيت ولقطات ونص شاشة وتعليق صوتي بالعربية والإنجليزية، مع كابشنين قابلين للتحرير. يمكن حفظ المسودة محليًا على الجهاز ونسخها أو تصديرها كملف TXT. لا ينشئ الاستوديو صورًا أو فيديو ولا يستخدم بيانات الحساب أو الإنترنت ولا ينشر تلقائيًا؛ راجع الحقائق وأضف تجربتك قبل الاستخدام. النتائج ليست توصيات مبنية على أداء منشورات حقيقية.

## بحث مؤشرات الترند العامة (مرحلة جديدة)

تبويب «بحث الترندات» يستعلم عند الطلب من موجز Google Trends العام `trending/rss`، افتراضيًا لمصر، ويعرض حتى 20 من أحدث استعلامات البحث المتاحة مع تصنيف حركة البحث التقريبي وسياق الأخبار الذي يورده الموجز. يمكن تغيير البلد عبر `geo` (رمز بلد من حرفين) في الواجهة/الـAPI. لا يحتاج إلى مفتاح مدفوع، ولا يقرأ Instagram ولا يجمع بيانات حسابك. الوصول للمسار يتطلب جلسة المالك لتقليل إساءة استخدامه كوسيط طلبات عام.

المسار `GET /api/trends/research?topic=...&geo=EG` يجلب فقط من مضيف Google Trends الثابت، بحجم/مهلة محدودة، ويرفض XML الذي يحتوي تعريفات DTD/ENTITY، ويعرض روابط أخبار HTTP(S) فقط. درجة الصلة من 0–100 هي تقاطع كلمات مفتاحية بسيط بين موضوعك وعناوين البحث/الأخبار؛ ليست نموذج ذكاء اصطناعي، ولا قياسًا لاتجاه Instagram أو اهتمام جمهورك، ولا توصية تلقائية بالنشر. الموجز صغير وحديث وقد لا يحتوي موضوعًا مناسبًا؛ استخدم زر تحويل الإشارة إلى مسودة ثم راجع دقتها وملاءمتها بنفسك. البحث حاليًا عند الطلب، وليس تقريرًا يوميًا آليًا؛ الترتيب المخصص بحسب أداء حسابك ينتظر ربط Instagram وميزات متابعة مجدولة. الوصول للموجز العام يعتمد على توفر خدمة Google واتصال الخادم بالإنترنت. اختبارات الموجز محلية بمحاكاة XML؛ وتم اختبار جلب الموجز العام حيًا مرة أثناء البناء، دون تسجيل دخول أو جمع بيانات Instagram.

## توليد الصور محليًا عبر ComfyUI (اختياري)

استوديو Reels يقدّم حقل وصف صورة قابلًا للتعديل. افتراضيًا يعيد التطبيق الوصف فقط بوضوح ولا يدّعي إنشاء صورة. يمكن لمالك الخادم تفعيل مسار اختياري إلى ComfyUI محلي عبر `IMAGE_GENERATOR=comfyui` بعد تثبيت ComfyUI وتنزيل نموذج/checkpoint متوافق، مثل SDXL. لا توجد خدمة مدفوعة أو مفتاح API؛ لكن تنزيل النموذج يحتاج عدة جيجابايت وقد يستهلك وقتًا وكهرباء. توليد SDXL عموديًا 768×1024 يحتاج عادةً بطاقة GPU بذاكرة VRAM كبيرة (يوصى بـ8GB أو أكثر)؛ ويمكن أن يعمل على CPU ببطء شديد حسب الإعداد.

اضبط `COMFYUI_BASE_URL` و`COMFYUI_CHECKPOINT` في بيئة الخادم فقط، ثم سجّل دخول المالك في اللوحة. لا يُكشف عنوان ComfyUI للمتصفح، ولا يقبل الخادم إلا عناوين loopback أو الشبكات الخاصة وأسماء خدمة محلية معروفة؛ كما يرسل رسم توليد ثابتًا محدودًا بدل قبول workflow اعتباطي. الطلب يتطلب مصادقة المالك، والصورة المحملة PNG واحدة بحد أقصى 5MB. لا تفتح ComfyUI أو API على الإنترنت العام؛ إن كان التطبيق على استضافة بعيدة، يجب أن يكون ComfyUI على شبكة خاصة يمكن لخادم API الوصول إليها بأمان—`localhost` يشير إلى جهاز الخادم نفسه، لا هاتف المستخدم. لا ترفع صورًا خاصة إلى خدمات عامة.

التوليد الحقيقي يعتمد على تنزيل ComfyUI والنموذج وإعداد العنوان ومصادقة المالك، ولم يُختبر هنا على خادم ComfyUI حي. الاختبارات تحاكي API محليًا لإثبات مسار الطلب والاستجابة والحماية، ولا تثبت أن العتاد أو النموذج مثبّت. عند غياب الإعداد أو فشله، تبقى الواجهة في وضع الوصف النصي فقط.

## مولّد محلي اختياري عبر Ollama (مجاني، غير مفعّل افتراضيًا)

يمكن تفعيل نموذج محلي متوافق مع Ollama دون اشتراك أو مفتاح لمزوّد مدفوع. يظل مولّد القوالب الحالي هو الوضع الافتراضي والبديل التلقائي إذا لم يعمل النموذج أو لم يُرجع بيانات صالحة. الاختيار على الخادم فقط عبر `CONTENT_GENERATOR=ollama`؛ عنوان Ollama والنموذج لا يأتيان من المتصفح، ولا تُرسل المسودات إلى خدمة خارجية. أسماء النماذج اختيارية وتتطلب تنزيل النموذج محليًا، ما يستهلك مساحة وذاكرة الجهاز.

1. ثبّت Ollama محليًا من موقعه الرسمي، ثم نزّل نموذجًا صغيرًا يدعم العربية مثل `qwen2.5:3b` (`ollama pull qwen2.5:3b`). لا توجد مفاتيح أو كلمات مرور مطلوبة لهذه الخطوة.
2. سجّل دخول المالك بإعداد `AMR_OWNER_PASSWORD_HASH` و`AMR_SESSION_SECRET` بالطريقة أعلاه؛ طلبات توليد النموذج تتطلب جلسة المالك. من `.env` على الخادم اضبط:

```sh
CONTENT_GENERATOR=ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:3b
```

3. شغّل Ollama والخادم، ثم افتح لوحة المحتوى وسجّل دخولك. سيظهر اسم المولّد، وتعمل أفكار المحتوى والكابشنات وسيناريوهات Reels؛ استوديو Reels يعيد مشاهد عربية وإنجليزية قابلة للتحرير. إذا تعطّل Ollama أو تعذّر تحليل الرد، يرجع التطبيق إلى القوالب المجانية مع تنبيه بذلك.

إعداد Ollama يقبل loopback أو عنوان IP خاص/محلي مضبوطًا يدويًا، ويرفض أسماء المضيف العامة، ويحظر التحويلات، ولا يستخدم إعدادات proxy من البيئة. لا تضع رابط Ollama في واجهة العميل، ولا تفتح منفذ Ollama على الإنترنت. لحاسوب منفصل على شبكة خاصة، يمكن ضبط عنوان IP الخاص لذلك الحاسوب بعد ضبط جدار الحماية؛ لا تستخدم `0.0.0.0` كعنوان اتصال. إعداد الهاتف لا يجعل `localhost` يشير إلى حاسوبك: استخدم عنوان API الذي يمكن للهاتف الوصول إليه، وOrigin مضبوطًا بدقة، وشبكة خاصة موثوقة/VPN وHTTPS عند الوصول عن بُعد. لا تعرض API أو Ollama للعامة بلا حماية ومراجعة نشر مناسبة. الواجهة متجاوبة مع الهاتف؛ معالجة النموذج تحصل على الخادم/الحاسوب الذي يشغّل Ollama، وليس داخل الهاتف.

الحالة متاحة من `GET /api/content/provider` ولا تكشف عنوان الخادم أو أي سر. اختيار Ollama يتطلب أيضًا إعداد مصادقة المالك؛ من دونها يبقى القالب المجاني هو المستخدم. الاختبارات تحاكي ردود النموذج ولا تثبت وجود Ollama أو النموذج على الجهاز. لم يُجرَ اختبار حي للنموذج في هذه المرحلة.


### تحليل أداء المحتوى
واجهة التحليلات تعرض أعلى المنشورات وReels ضمن أحدث عينة تعيدها واجهة Instagram Graph الرسمية (افتراضيًا 12 عنصرًا)، وفق مجموع `like_count` و`comments_count` فقط عندما يعيد Meta القيمتين. المجموع مؤشر وصفي جزئي، وليس إجمالي `total_interactions` أو معدل تفاعل مطبّعًا بعدد الوصول/المشاهدات، ولا يفسر سبب نجاح المحتوى. لا تظهر العناصر ذات القيم المفقودة أو غير الصالحة في الترتيب، ويظهر عددها منفصلًا؛ الصفر يُعرض فقط عندما أعاد Meta صفرًا فعلًا. المقارنة ليست عبر كل محتوى الحساب إلا بعد متابعة المؤشر `next_after` إلى الصفحات التالية؛ الواجهة الحالية تعرض العينة الأخيرة فقط.

في لوحة Insights، يعرض ملخص التغير فرق أول وآخر نقطة يومية متاحة لكل مقياس خلال الفترة المحددة. لا يظهر فرق عند عدم وجود نقطتين صالحتين، ولا يُحسب تغير نسبي إذا كانت نقطة البداية صفرًا. هذه مقارنة وصفية ولا تثبت علاقة سببية. فشل أو غياب قيمة Meta لا يتحول إلى صفر.



## مراجعة الملف الشخصي (مراجعة فقط)

تضيف صفحة الإعدادات وحدة لمراجعة الملف الشخصي بالعربية والإنجليزية، ويمكن فتحها من شريط التنقل على الهاتف. تعتمد بيانات Instagram الرسمية فقط على الحقول التي يعيدها التكامل الحالي (`user_id`, `username`, `account_type`, `media_count`). لا يطلب هذا المسار حقول النبذة أو اسم العرض أو صورة الملف أو الموقع، لذلك لا يعرضها كبيانات مؤكدة ولا يستنتجها من المنشورات. أدخل اسم العرض والنبذة والمجال والجمهور والعرض والموقع يدويًا إن أردت فحصًا محدودًا؛ توسم هذه القيم بوضوح كمدخلات يدوية، ولا تحفظها الوحدة في قاعدة بيانات أو متصفح التطبيق.

الفحوص الآلية محدودة لقياس طول النبذة والبحث عن عبارات CTA شائعة/مطابقة لنص المجال اليدوي؛ هذه إشارات نصية بسيطة لا تقيس الوضوح أو التحويل أو جودة الملف. تعرض الوحدة أسئلة مراجعة لصورة الملف والهوية البصرية لأنهما غير متاحين عبر حقول التكامل الحالي. التقرير اقتراحات قابلة للمراجعة فقط: لا توجد كتابة إلى Instagram أو تعديل للملف أو تعديل Bio عبر هذا المسار. يتطلب endpoint مصادقة المالك، ويفشل اتصال Meta أو غيابه لا يتحول إلى بيانات مفترضة.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

اختبارات Instagram تستبدل طلبات Meta بمحاكاة محلية؛ لا تتصل بالإنترنت ولا تنشئ اتصالًا حيًا أو تنشر محتوى. تشمل مصادقة المالك والجلسات وقيود Origin، تدفق OAuth/CSRF والتشفير، قراءة الحساب والمنشورات وInsights، ونشر صورة/Reel وجدولته/إلغاءه والموافقة الصريحة والتعامل الآمن مع نتيجة نشر مبهمة.

## التكلفة والحدود الحالية

لا توجد رسوم متعمدة أو خدمات مدفوعة في مرحلة النشر البرمجية هذه؛ تشغيل الاختبارات محلي ومجاني. لا نضمن استمرار الخطط المجانية للاستضافة، ولا تشمل التكاليف استضافة فعلية أو نطاقًا أو ميزات نماذج ذكاء اصطناعي مستقبلية. لا توجد رسوم API معلومة لنا هنا، لكن الوصول يتطلب تطبيق Meta وموافقاتها وقد تتغير الصلاحيات والحدود.

## المراحل

1. هيكل FastAPI/Next.js واختباره (منجز).
2. لوحة عربية/إنجليزية متجاوبة بحالات فارغة صريحة (منجز).
3. مساعد القوالب المجاني افتراضيًا؛ خيار Ollama محلي اختياري مع fallback واختبارات محاكاة؛ استوديو Reels عربي/إنجليزي قابل للتحرير والتصدير، مع مسار صور ComfyUI اختياري ومحاكاة اختبارات؛ لا يزال التوليد الحي غير مختبر.
4. هيكل OAuth رسمي آمن وتجارب mock فقط (مكتمل؛ لم يختبر حسابًا حيًا).
5. واجهة تسجيل دخول المالك وعرض بيانات الحساب والمنشورات الرسمية (مكتملة محليًا؛ لم يختبر حسابًا حيًا).
6. إعداد تطبيق Meta ومراجعته ثم اختبار ربط حي بموافقة المالك (ما زال مطلوبًا).
7. تحليلات Insights الرسمية للحساب والوسائط (تنفيذ تجريبي بالمحاكاة؛ يلزم اختبار حي).
8. النشر الرسمي للصورة والفيديو وReel مع موافقة صريحة وجدولة مُدارة من التطبيق (مكتمل بالاختبارات المحاكية؛ لم يُختبر حساب حي). يظل ربط OAuth الحي وإعداد تطبيق Meta لازمًا قبل النشر الفعلي.
9. بحث مؤشرات Google Trends العامة ومطابقة الكلمات المفتاحية الأولية لموضوع المحتوى (مكتمل؛ لا يعرض ترندات Instagram أو بيانات الجمهور).
10. مراجعة الملف الشخصي بالعربية والإنجليزية عبر الحقول الرسمية المتاحة ومدخلات يدوية اختيارية؛ مراجعة فقط دون كتابة للملف (مكتمل بالاختبارات المحاكية، لا توجد بيانات حساب حية).

## الإعدادات

لا توجد مفاتيح خارجية مطلوبة لتجربة لوحة التحكم ومساعد القوالب محليًا. مولّد Ollama خيار محلي إضافي موضح أعلاه. الواجهة تستخدم `http://localhost:8000` كعنوان API افتراضي؛ اضبط `NEXT_PUBLIC_API_BASE_URL` عند نشر واجهة وخادم على نطاقات معلومة، و`WEB_ORIGIN` للسماح بأصل الواجهة فقط. للاستخدام من الهاتف، افتح نشرًا خاصًا محميًا أو شبكة محلية مضبوطة؛ لا تستخدم `localhost` على الهاتف للإشارة إلى جهاز التطوير. لا تفتح OAuth على الإنترنت قبل وجود مصادقة للمالك.

انسخ `.env.example` إلى `.env` عند الحاجة. لا ترفع ملفات `.env` أو قاعدة بيانات الرموز إلى GitHub.


## تجهيز مسودة Reel بصورك (تصدير محلي)

من داخل لوحة Storyboard، اختر صورًا ثابتة تملكها أو لديك ترخيص لاستخدامها، ثم رتّب المشاهد وحدد مدة كل صورة (1–60 ثانية)، ويمكن إضافة ملف صوت مرخّص. التصدير ينزّل `amr-reel-draft-bundle.zip` الذي يحتوي الصور المختارة و`render.sh` وشرحًا مختصرًا. الصور والصوت لا يُرفعان إلى API؛ يرسل المتصفح امتدادات الملفات ومدد المشاهد فقط لإعداد أمر FFmpeg. لا يُنشر أي شيء إلى Instagram.

هذه أداة مساعدة محلية وليست محرر فيديو كاملًا: الناتج عرض شرائح من صور ثابتة بلا نصوص أو انتقالات أو قصّ فيديو، بصيغة MP4/H.264، مقاس عمودي 720×1280 و30 إطارًا/ثانية، حتى 12 صورة و180 ثانية إجمالًا. الصوت اختياري ويُحوّل إلى AAC. يلزم تثبيت FFmpeg على جهازك لتصيير MP4؛ التطبيق لا يشغّل FFmpeg على الخادم ولا يضمّنه في الموقع. راجع معاينة الناتج محليًا قبل أي استخدام.

على كمبيوتر أو Android مع Termux: فك ضغط الحزمة في مجلد، ثبّت FFmpeg على الجهاز (في Termux: `pkg install ffmpeg`)، ثم شغّل `bash render.sh` داخل المجلد. في Android قد تحتاج إلى إعداد صلاحية التخزين في Termux ونقل ملف ZIP يدويًا. لا تُضف إلا موسيقى/صورًا مرخّصة، ولا تشارك الحزمة التي تتضمن ملفاتك الخاصة. إذا لم يكن لديك FFmpeg أو لم يكن جهازك قادرًا على تشغيله، فالتصدير يظل حزمة تحضير لا ملف فيديو نهائيًا.

## مركز تشغيل الأدوات

تعرض صفحة النظرة العامة اختصارات إلى وحدات المشروع الموجودة: أفكار وكابشنات، استوديو Reels، مراجعة الملف الشخصي، بحث الترندات، تحليلات الحساب، تقرير الاستراتيجية، وتقويم مراجعة/جدولة المنشورات. هذه البطاقات تنقلك إلى الوحدات الحالية ولا تنفّذ نشرًا أو اتصالًا بحساب. يظل كل نشر خلف مراجعة وموافقة منفصلة في التقويم. بحث الترندات يعتمد إشارات Google العامة، لا ترندات Instagram؛ التحليلات والبيانات الشخصية تحتاج اتصال Instagram رسميًا وصلاحيات مناسبة.

تُفحص روابط مركز الأدوات ضمن اختبارات `uv run pytest`، ويُتحقق من واجهة الإنتاج عبر `cd web && npm run build`.

# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. هذه المرحلة تضع هيكل المشروع وخدمة API واختبار صحة بسيطًا؛ لا يوجد اتصال بـ Instagram أو بيانات حساب فعلية بعد.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload
```

افتح `/healthz` لفحص الخدمة و`/docs` لواجهة FastAPI التفاعلية.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

## حدود المرحلة الحالية

- لا يتصل المشروع بـ Meta أو Instagram، ولا يطلب كلمة مرور أو رمز تحقق.
- الواجهة في `web/` هي نقطة بداية فقط، وليست لوحة مكتملة أو مصدر بيانات حقيقية.
- لا توجد مهام نشر أو جدولة فعلية؛ لن ينشر النظام أي محتوى.
- تكامل Instagram الرسمي سيأتي بعد التحقق من صلاحيات Meta وإعداد OAuth الآمن.

## المراحل

1. الهيكل الأساسي، API health check، والاختبارات (هذه المرحلة).
2. لوحة عربية/إنجليزية متجاوبة ببيانات حالة صريحة، دون بيانات وهمية على أنها حقيقية.
3. إنشاء محتوى وسكربتات ومقترحات مع واجهة مزود AI قابلة للتبديل.
4. OAuth رسمي لحساب Creator والتحقق من صلاحيات Meta دون تخزين كلمات المرور.
5. تحليلات ونشر/جدولة ضمن الصلاحيات المتاحة، مع موافقات وسجل عمليات واختبارات تكامل.

## إعداد الأسرار

انسخ `.env.example` إلى `.env` عند الحاجة. لا تضع ملفات `.env` أو الرموز السرية في GitHub.

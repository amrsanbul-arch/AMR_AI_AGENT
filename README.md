# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. تتضمن لوحة عربية/إنجليزية متجاوبة، ومساعد محتوى محليًا، وهيكلًا لتكامل Instagram Login الرسمي. لا يوجد حساب Instagram حي متصل في هذه النسخة.

## تشغيل لوحة التحكم

يتطلب Node.js 20+ وpnpm:

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Next.js. الواجهة متجاوبة وتدعم العربية RTL والإنجليزية. مساعد المحتوى يجهز مسودات أفكار وكابشنات وسيناريوهات محلية قابلة للتحرير؛ لا يستخدم نموذجًا خارجيًا ولا ينشر تلقائيًا. التقويم والتحليلات ما زالت هياكل أولية.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload --no-access-log
```

`--no-access-log` يمنع سجل Uvicorn من تسجيل عنوان callback الذي قد يحتوي على رمز تفويض مؤقت. افتح `/healthz`, `/api/instagram/status` أو `/docs`. عند استخدام reverse proxy، اضبط سجلاته كي لا تحفظ query string لمسار `/api/instagram/callback`.

## Instagram Login الرسمي (مرحلة تمهيدية، غير موصلة)

تمت إضافة مسارات OAuth الرسمية مع أقل صلاحية للقراءة الأساسية (`instagram_business_basic`)، والتحقق من `state` بملف تعريف ارتباط HttpOnly قصير العمر، وتبادل authorization code على الخادم، وتشفير رمز الوصول طويل العمر في SQLite باستخدام Fernet. لا تُعاد الرموز السرية في الاستجابات، ولا توجد بيانات حساب مضمّنة. تُستخدم فقط نطاقات Instagram الرسمية (`instagram.com`, `api.instagram.com`, `graph.instagram.com`).

قبل الاختبار يدويًا، يلزم إعداد تطبيق Meta للمطور وتحديد Instagram Login وإضافة Redirect URI المطابق تمامًا. ضع القيم محليًا في `.env` (لا ترفع الملف إلى Git):

```sh
cp .env.example .env
```

املأ `META_APP_ID`, `META_APP_SECRET`, `META_REDIRECT_URI=http://localhost:8000/api/instagram/callback`. أنشئ `INSTAGRAM_TOKEN_ENCRYPTION_KEY` محليًا بالأمر الموجود في `.env.example`. لا ترسل أسرار Meta أو مفتاح التشفير إلى Wabi أو GitHub. عند اكتمال الإعداد محليًا، يمكن بدء تدفق التفويض من `/api/instagram/connect`; حالة الحساب تقرأ من `/api/instagram/status`; حذف الرمز المحفوظ محليًا يتم عبر `POST /api/instagram/disconnect`.

هذه المرحلة لم تستخدم بيانات اعتماد حقيقية أو حسابًا مباشرًا؛ نجاح الاختبارات لا يثبت أن Meta وافقت على التطبيق أو أن الربط الحقيقي يعمل. لا تشغّل OAuth في الإنتاج: المشروع لا يحتوي بعد على تسجيل دخول/تحقق من مالك لوحة التحكم، ولذلك تُعطل المسارات إذا كان `APP_ENV=production`. يلزم إضافة حماية مالك موثقة قبل فتحها عبر الإنترنت. إعدادات التطوير تسمح فقط بعنوان callback محلي أو HTTPS ثابت على مسار callback المحدد. رموز OAuth تمر في طلبات الخادم المطلوبة من Meta؛ لا تفعّل سجلات HTTP أو proxy التي تحفظ query string لهذه الطلبات/المسارات.

التدفق لا يمنح إلا صلاحية الملف الأساسي؛ لا يوجد نشر أو قراءة Insights أو التعليقات أو الرسائل بعد. إضافة كل صلاحية أخرى تتطلب مطابقة وثائق Meta الحالية ومراجعتها واختبارها منفصلًا. لا يغيّر disconnect الصلاحيات لدى Meta؛ يلزم إلغاء التطبيق من إعدادات Instagram عند الحاجة. إدارة صلاحية الرمز وتجديده ستضاف عند تنفيذ استخدام API الفعلي.

## مساعد المحتوى

المولّد الحالي محلي مجاني وحتمي، وليس نموذج AI/LLM. يجهز أفكارًا وكابشنات وسيناريوهات Reel قابلة للتعديل ولا يستخدم بيانات الحساب أو الإنترنت. النتائج مسودات وليست توصيات مبنية على أداء منشورات حقيقية.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

اختبارات Instagram تستبدل طلبات Meta بمحاكاة محلية؛ لا تتصل بالإنترنت ولا تنشئ اتصالًا حيًا أو بيانات مستخدم. اختبارات OAuth تغطي الحالة غير المهيأة، ومسارات التفويض والحالة، وفشل التحقق، والتبادل الوهمي للرمز وتشفيره، وحذف الرمز محليًا.

## التكلفة والحدود الحالية

لا توجد رسوم متعمدة أو خدمات مدفوعة في مرحلة OAuth هذه؛ تشغيل الاختبارات محلي ومجاني. لا نضمن استمرار الخطط المجانية للاستضافة، ولا تشمل التكاليف استضافة فعلية أو نطاقًا أو ميزات نماذج ذكاء اصطناعي مستقبلية. لا توجد رسوم API معلومة لنا هنا، لكن الوصول يتطلب تطبيق Meta وموافقاتها وقد تتغير الصلاحيات والحدود.

## المراحل

1. هيكل FastAPI/Next.js واختباره (منجز).
2. لوحة عربية/إنجليزية متجاوبة بحالات فارغة صريحة (منجز).
3. مساعد محلي للأفكار والكابشنات وسيناريوهات Reels (منجز؛ لا يستخدم LLM).
4. هيكل OAuth رسمي آمن وتجارب mock فقط (منجز مبدئيًا؛ لم يختبر حسابًا حيًا، ومقيد بالتطوير المحلي دون مصادقة المالك).
5. بعد إنشاء وحماية تطبيق Meta: فحص اتصال حي بموافقة المالك، ثم توسيع الصلاحيات حسب الحاجة. التحليلات والنشر والجدولة ليست موجودة بعد.

## الإعدادات

لا توجد مفاتيح خارجية مطلوبة لتجربة لوحة التحكم ومساعد المحتوى محليًا. الواجهة تستخدم `http://localhost:8000` كعنوان API افتراضي؛ اضبط `NEXT_PUBLIC_API_BASE_URL` عند نشر واجهة وخادم على نطاقات معلومة، و`WEB_ORIGIN` للسماح بأصل الواجهة فقط. للاستخدام من الهاتف، افتح نشرًا خاصًا محميًا أو شبكة محلية مضبوطة؛ لا تستخدم `localhost` على الهاتف للإشارة إلى جهاز التطوير. لا تفتح OAuth على الإنترنت قبل وجود مصادقة للمالك.

انسخ `.env.example` إلى `.env` عند الحاجة. لا ترفع ملفات `.env` أو قاعدة بيانات الرموز إلى GitHub.

# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. تم إنجاز الهيكل الأساسي والمرحلة الثانية: لوحة تحكم عربية/إنجليزية متجاوبة مع حالات فارغة صريحة. لا يوجد اتصال بـ Instagram أو بيانات حساب فعلية بعد.

## تشغيل لوحة التحكم

يتطلب Node.js 20+ وpnpm:

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Next.js. الواجهة متجاوبة، ويمكن التبديل بين العربية والإنجليزية من زر اللغة؛ الصفحات الرئيسية والتنقل تعمل، أما الاستوديو والتقويم والتحليلات فواجهات أولية بلا وظائف خلفية أو بيانات فعلية.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload
```

افتح `/healthz` لفحص الخدمة و`/docs` لواجهة FastAPI التفاعلية.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

## حدود المرحلة الحالية

- لا يتصل المشروع بـ Meta أو Instagram، ولا يطلب كلمة مرور أو رمز تحقق.
- لوحة التحكم في `web/` هي واجهة مرحلة ثانية؛ بطاقات الأرقام والمحتوى تعرض حالات فارغة بدل اختلاق بيانات، ولا تمثل بعد لوحة مربوطة بالحساب.
- لا توجد مهام نشر أو جدولة فعلية؛ لن ينشر النظام أي محتوى.
- تكامل Instagram الرسمي سيأتي بعد التحقق من صلاحيات Meta وإعداد OAuth الآمن.

## المراحل

1. الهيكل الأساسي، API health check، والاختبارات (منجزة).
2. لوحة تحكم عربية/إنجليزية متجاوبة وحالات صريحة دون بيانات وهمية (منجزة؛ بناء Next.js ناجح).
3. إنشاء محتوى وسكربتات ومقترحات مع واجهة مزود AI قابلة للتبديل (لاحقًا).
4. OAuth رسمي لحساب Creator والتحقق من صلاحيات Meta دون تخزين كلمات المرور.
5. تحليلات ونشر/جدولة ضمن الصلاحيات المتاحة، مع موافقات وسجل عمليات واختبارات تكامل.

## إعداد الأسرار

انسخ `.env.example` إلى `.env` عند الحاجة. لا تضع ملفات `.env` أو الرموز السرية في GitHub.

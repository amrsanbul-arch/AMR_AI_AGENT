# AMR AI – Personal Instagram Manager

نسخة أولية قابلة للتعديل. تم إنجاز الهيكل الأساسي والمرحلة الثانية: لوحة تحكم عربية/إنجليزية متجاوبة مع حالات فارغة صريحة. لا يوجد اتصال بـ Instagram أو بيانات حساب فعلية بعد.

## تشغيل لوحة التحكم

يتطلب Node.js 20+ وpnpm:

```sh
cd web
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Next.js. الواجهة متجاوبة، ويمكن التبديل بين العربية والإنجليزية من زر اللغة؛ الصفحات الرئيسية والتنقل تعمل، استوديو المحتوى يعمل محليًا عبر API لتوليد مسودات أفكار وكابشنات وسيناريوهات؛ التقويم والتحليلات ما زالت واجهات تأسيسية.

## تشغيل API محليًا

يتطلب Python 3.11+ و`uv`:

```sh
uv sync --extra dev
uv run uvicorn app.main:app --app-dir api --reload
```

افتح `/healthz` لفحص الخدمة و`/docs` لواجهة FastAPI التفاعلية. لتجربة استوديو المحتوى، شغّل الواجهة والـ API معًا؛ الإعدادات المحلية الافتراضية موجودة في `.env.example`.

## الاختبارات

```sh
uv sync --extra dev
uv run pytest
```

## حدود المرحلة الحالية

- لا يتصل المشروع بـ Meta أو Instagram، ولا يطلب كلمة مرور أو رمز تحقق.
- لوحة التحكم في `web/` هي واجهة مرحلة ثانية؛ بطاقات الأرقام والمحتوى تعرض حالات فارغة بدل اختلاق بيانات، ولا تمثل بعد لوحة مربوطة بالحساب.
- مساعد المحتوى الحالي قوالب محلية مجانية وحتمية، وليس نموذجًا توليديًا أو LLM؛ لا يستخدم حساب Instagram أو خدمة خارجية، وكل النتائج تحتاج مراجعة وتحريرًا.
- تكامل Instagram الرسمي سيأتي بعد التحقق من صلاحيات Meta وإعداد OAuth الآمن.

## المراحل

1. الهيكل الأساسي، API health check، والاختبارات (منجزة).
2. لوحة تحكم عربية/إنجليزية متجاوبة وحالات صريحة دون بيانات وهمية (منجزة؛ بناء Next.js ناجح).
3. مساعد محتوى محلي: أفكار، كابشن، وسيناريو Reel بالعربية والإنجليزية؛ API وواجهة متجاوبة واختبارات. التكامل مع نموذج AI فعلي قابل للتبديل خطوة تالية.
4. OAuth رسمي لحساب Creator والتحقق من صلاحيات Meta دون تخزين كلمات المرور.
5. تحليلات ونشر/جدولة ضمن الصلاحيات المتاحة، مع موافقات وسجل عمليات واختبارات تكامل.

## إعداد البيئة

لا توجد مفاتيح API أو تكاليف مطلوبة لمساعد المحتوى المحلي. محليًا، يستخدم الـ API `http://localhost:3000` كأصل مسموح، والواجهة `http://localhost:8000` كعنوان API افتراضي. عند الاستضافة، عيّن `WEB_ORIGIN` إلى نطاق الواجهة و`NEXT_PUBLIC_API_BASE_URL` إلى نطاق API قبل بناء Next.js؛ لا تفتح CORS على كل النطاقات. للوصول من الهاتف، انشر الواجهة والـ API على نطاقات فعلية أو استخدم عنوانًا شبكيًا موثوقًا واضبط CORS؛ لا تستخدم `localhost` في الهاتف كأنه يشير إلى جهاز التطوير.

## إعداد الأسرار

انسخ `.env.example` إلى `.env` عند الحاجة. لا تضع ملفات `.env` أو الرموز السرية في GitHub.
